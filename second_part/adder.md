### Полусумматор

Ранее мы поняли, что при сложении двух чисел может возникнуть переход из одного разряда в другой. Тогда таблица истинности полусумматора будет выглядеть следующим образом:

<p align="center">
  <img width="1470" height="720" alt="Half_Adder_table" src="https://github.com/user-attachments/assets/687ae378-33cf-4a27-ab2b-12adcbf496c8" />
</p>


S - сумма <br>
C - переход в следующий разряд

Глядя на таблицу истинности мы можем сказать, что к нам приходят два числа A и B. В случае, если A и B оба равны нулю, сумма, соответственно будет 0, если A = 1, B = 0 или наоборот S = 1, переноса не возникает, а вот если, A и B оба равны единице, в этом разряде сумма будет равна нулю, и единица от этого сложения перенесётся в следующий разряд. То есть, S = 0, а перенос равен C = 1. Логически данную таблицу истинности можно описать так:

$$
\begin{aligned}
  S &= A \oplus B \\
  C &= A \cdot B
\end{aligned}
$$

Тогда на System Verilog полусумматор можно описать следующим образом:

```systemverilog
module half_adder(
    input  logic A,
    input  logic B,
    output logic S,
    output logic C
);

   assign S = A ^ B;
   assign C = A & B;
endmodule
```

Проверяя работоспособность схемы на временных диаграммах, мы видим следующее:

<p align="center">
  <img width="1390" height="191" alt="image" src="https://github.com/user-attachments/assets/32129d65-0d08-4647-9dbc-811781523e1d" />
</p>

В ситуации, когда A = 0, B = 0 сумма S равна 0 и переноса С также нет <br>

В ситуации, когда A = 0, B = 1 сумма S равна 1, но перенос при этом ещё не "накопился" <br>

Ситуация, когда A = 1, B = 0 сумма S аналогична предыдущей <br>

И в случае, когда A = 1, B = 1 сумма S равно 0, зато перенос равен 1 <br>

### Полный сумматор

Мы рассмотрели вариант полусумматора. В нём учитывается только то, что после сложения может образоваться перенос. А как быть, если перенос пришёл к нам из другого разряда, как это было в случае со сложением 25 и 36, например, когда из разряда единиц число 1 перешло в десятки? Подобные ситуации побудили расширить неполный сумматор, добавив в него перенос, который приходит к нам из другого разряда. Таблица истинности такого сумматора будет следующей:

<p align="center">
  <img width="1471" height="720" alt="full_adder_truth_table" src="https://github.com/user-attachments/assets/e53e42c4-9e90-4ef0-9b2b-270391a6a68e" />
</p>

Построчно рассматривая данную таблицу истинности, можно выявить следующее:

Если A = 0, B = 0, Cin = 0, то и сумма вместе с выходным переносом так же равны нулю <br>

Если A = 0, B = 0, Cin = 1, то сумма будет равна 1. Вспомни сложение 64 и 81. Сложив 6 и 8, которые находились в десятках, мы получили 14, после чего 4 оставили в десятках, а 1 перенесли в сотни. Здесь происходит подобная ситуация, в сотнях как у первого, так и у второго числа 0, но при этом пришёл переход из другого разряда <br>

Если A = 0, B = 1, Cin = 0 сумма S равна 1, переноса Cout нет <br>

Если A = 1, B = 0, Cin = 0 происходит ситуация, подобная предыдущей <br>

Если A = 0, B = 1, Cin = 1 сумма S равна 0, но при этом происходит перенос Cout в следующий разряд <br>

Если A = 1, B = 0, Cin = 0 сумма S равна 1, переноса Cout нет <br>

Если A = 1, B = 0, Cin = 1 сумма S равна 0, но при этом происходит перенос Cout в следующий разряд <br>

Если A = 1, B = 1, Cin = 0 сумма S равна 0, но при этом происходит перенос Cout в следующий разряд <br>

Если A = 1, B = 1, Cin = 1 в это случае и S и Cout равны 1

Рассмотрев таблицу истинности полного сумматора, мы можем составить его логическое выражение. S равна 1, если 

* Cin равна единице, всё остальное равно 0
* Вход B равен единице, всё остальное равно 0
* Вход A равен единице, всё остальное равно 0
* Вход A, вход B и перенос равны 1

Тогда S:

$$S = \overline{A}\overline{B}C_{in} \mid \overline{A}B\overline{C}_{in} \mid A\overline{B}\overline{C}_{in} \mid ABC_{in}$$

Применив чудеса булевой алгебры, приходим к вот такому вот выражению:

$$S = A \oplus B \oplus C_{in}$$

Выходной перенос Cout равен 1, если

* Вход B равен 1 и входной перенос Cin также равен 1
* Вход A равен 1 и входной перенос Cin также равен 1
* Вход A и вход B равны 1
* Вход A, вход B и входной перенос равны 1

Тогда Cout:

$$C_{out} = \overline{A}BC_{in} \mid A\overline{B}C_{in} \mid AB\overline{C}_{in} \mid ABC_{in}$$

Применив чудеса булевой алгебры, приходим к вот такому вот выражению:

$$C_{out} = AB \mid AC_{in} \mid BC_{in}$$

>[!NOTE]
>  Задание:
>  Опишите на System Verilog полный однобитный сумматор

Шапка модуля:

```systemverilog
module full_adder(
    input  logic A,
    input  logic B,
    input  logic Cin,

    output logic S,
    output logic Cout
);

endmodule
```
