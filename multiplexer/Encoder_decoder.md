# Шифраторы и дешифраторы

Шифратор – комбинационное логическое устройство, которое преобразует позиционный (унитарный) входной код в равнозначный двоичный, троичный или k-ичный позиционный код на выходе
Представим, что у нас есть ПЛИС, пусть это будет Basys 3

На ней 16 свитчей, и вот представим, что нам нужно, чтобы информация о том, какой конкретно свитч сейчас в активном состоянии передавалась на семисегментный индикатор. Например, в активном состоянии восьмой свитч и на семисегментном индикаторе мы видим 8 (8 в шестнадцатеричной системе счисления).

На System Verilog данная концепция будет выглядеть следующим образом:

```systemverilog
module encoder (
    input  logic [15:0] sw,
    output logic [3:0]  switch_number
);

    always_comb begin
        case(sw)
        16'b0000_0000_0000_0001: switch_number = 4'd0;
        16'b0000_0000_0000_0010: switch_number = 4'd1;
        16'b0000_0000_0000_0100: switch_number = 4'd2;
        16'b0000_0000_0000_1000: switch_number = 4'd3;
        16'b0000_0000_0001_0000: switch_number = 4'd4;
        16'b0000_0000_0010_0000: switch_number = 4'd5;
        16'b0000_0000_0100_0000: switch_number = 4'd6;
        16'b0000_0000_1000_0000: switch_number = 4'd7;
        16'b0000_0001_0000_0000: switch_number = 4'd8;
        16'b0000_0010_0000_0000: switch_number = 4'd9;
        16'b0000_0100_0000_0000: switch_number = 4'd10;
        16'b0000_1000_0000_0000: switch_number = 4'd11;
        16'b0001_0000_0000_0000: switch_number = 4'd12;
        16'b0010_0000_0000_0000: switch_number = 4'd13;
        16'b0100_0000_0000_0000: switch_number = 4'd14;
        16'b1000_0000_0000_0000: switch_number = 4'd15;
        default:                 switch_number = 4'd0;

        endcase
    end
endmodule
```

Кроме того, шифратор так же, как и мультиплексор можно описать при помощи логического выражения.
